# Frozen first-release protocol

Registered October 5, 2026, before the first candidate trial. Recipe v1 uses
32 ordered byte features, 2 to 4 centroid owners, separate 257-symbol text and
4-action code heads, scalar owned Adam, and a 16 by 16 toroidal B3/S23 world.
The shared encoder is deterministic and frozen. No learned cell interventions or
merges are admitted in this recipe. These are unresolved research extensions.

Mechanism gates: analytical derivatives within 1e-5 of central finite differences;
masked owners byte-identical including moments and clocks; no update without a
physical cross-lineage contact; causal source input never includes its target;
same-build continuous, split-call and checkpoint-resumed state identical;
corrupt/truncated/trailing checkpoints rejected without replacing the incumbent.

Finite edit family: an inclusive range predicate. Four declared candidates are
baseline, lower-only, upper-only, and both bounds. TRAIN correctness alone defines
the supervised choice. AUDIT uses disjoint (lower, upper, input) rows and authored
boundary/interior/outside families; individual scalar values may overlap. AUDIT
may gate publication, never fitting or action selection. A successful trial must
retain all four attempts, compile and execute native evaluators, improve TRAIN
failure count and pass AUDIT. Compilation alone earns no quality reward. Report
all denominators, infrastructure failures, output changes and execution costs.

Sequence gate: exact byte and EOS targets from immutable TRAIN source, compared
against target-free frozen inference. Show lower source reconstruction loss after
genuine encounters. This demonstrates learned fixture behavior, not arbitrary
code generation. Retention and transfer require separate frozen authored families.

Future experiments must preregister Life and deterministic learned-scheduler
comparators with identical data, model, optimizer and update budgets. Include a
declared zero-update frozen/no-learning comparator; it cannot have the learned
comparators' update count. Record scheduler and total compute separately, including
remaining mismatches. Independent families, not additional seeds
of one predicate, are required for claims about general coding improvement.
