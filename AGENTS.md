# Project working contract

Read research/ROADMAP.md before widening scope. The original design is retained
in research/archive/FRESH_START_BLUEPRINT.md. All authored executable
workflows, evaluators, tests and runtime code use strict C11. Declare toolchain
dependencies; do not add a script runtime or service requirement.

Production parameter mutation belongs to src/life/trainer.c. Numerical helpers
remain internal. Inference does not train or execute tools. A physical B3/S23
encounter must authorize every production parameter update. Shared representation
is frozen in the first recipe. Keep unrelated owners and heads unchanged.

Later shared-representation, cell-policy and merge work uses isolated candidate
forks with explicit permissions and independent retention/publication gates.
Shared learning requires all live owners at a physical encounter; policy teachers
use world geometry only. Merges require parent contact and preserve retired task
provenance and consumed receipts. Failed candidates remain retained, and research
schedulers or opened AUDIT results never silently replace the production recipe.

LLM proposals and activity are attributed inputs, never automatic target labels.
Holdout data cannot enter retrieval or training. Keep all attempted candidate
results. Infrastructure passes do not establish general coding improvement.

Preserve complete bytes and provenance, reject capacity overflow explicitly, and
validate complete checkpoint candidates before replacing an incumbent. Add tests
for meaningful mathematical, ownership, continuation and verification contracts.
